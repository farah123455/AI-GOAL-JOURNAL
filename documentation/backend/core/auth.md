# auth.py (Firebase Authentication & Security Guard)

## 📌 What This File Does
This file is the **security bouncer** for the entire backend. It ensures that every time a request comes in (like viewing private journals or creating goals), the user is who they claim to be.

It takes the login token generated by Firebase Authentication in the frontend and verifies it against Google's servers. If valid, it extracts the user's unique identity (Firebase UID) and allows the request through.

---

## 📥 Where It Gets Data
- **Authorization Header**: Reads the incoming HTTP header `Authorization: Bearer <FIREBASE_ID_TOKEN>` sent by the React frontend.
- **Firebase Admin SDK / Google Public Keys**: Contacts Firebase security servers to cryptographically verify the signature of the token.

---

## ⚙️ How It Works (Step-by-Step)
1. **Token Extraction**: Grabs the Bearer token from the incoming web request.
2. **Cryptographic Verification**:
   - Decodes and verifies the token using Google Firebase Admin public keys.
   - Checks if the token is expired or altered.
3. **User Isolation**:
   - Extracts the authenticated `uid`, `email`, and name.
   - Attaches the verified user information to the FastAPI request context.
   - Guarantees that User A can never read or modify User B's journals, goals, or roadmaps.
4. **Error Handling**: If a token is fake, expired, or missing, it rejects the request with an HTTP 401 Unauthorized error before any database or AI code runs.

---

## 📤 Where the Output Goes
- Injects the authenticated user object (`current_user`) directly into FastAPI route handlers so services know exactly whose data to fetch or modify.

---

## 🎤 How to Explain to an Evaluator / Interviewer
> *"If asked 'How do you handle authentication?': The frontend logs in through Firebase Auth, which issues a secure JWT token. Our backend `auth.py` validates this token on every protected API call using the Firebase Admin SDK. This guarantees user-level data isolation so no user can ever access another user's personal journals or goals."*
